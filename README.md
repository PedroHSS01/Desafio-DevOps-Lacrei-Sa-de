# Desafio DevOps - Lacrei Saúde 💙

## 📋 Sobre o Projeto
Aplicação Node.js simples para demonstração de pipeline CI/CD com deploy automatizado em ambientes de staging e produção na AWS.

## 🚀 Tecnologias Utilizadas
- Node.js + Express
- Docker
- GitHub Actions
- AWS

## 📦 Como Rodar Localmente

### Pré-requisitos
- Node.js 18+
- Docker (opcional)

### Instalação
\`\`\`bash
npm install
npm start
\`\`\`

Acesse: http://localhost:3000/status

### Com Docker
\`\`\`bash
docker build -t lacrei-app .
docker run -p 3000:3000 lacrei-app
\`\`\`
